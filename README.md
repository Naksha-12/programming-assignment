
# Programming Assignment

This repository contains three JavaScript-based applications developed as part of a programming assignment.

## 1. Login and Registration System
A React-based authentication application with an Express.js backend and SQLite database.

Features:
- User registration
- Secure password hashing using bcrypt
- User login and validation
- JWT authentication token

Folder: `login-registration/`

## 2. LLM and RAG Application
An AI document assistant that uses Retrieval Augmented Generation to answer questions from uploaded text documents.

Features:
- Text document upload
- Document chunking
- Relevant information retrieval
- AI-generated answers using OpenAI

Folder: `llm-rag/`

## 3. AI Website Summarizer
An application that accepts a website URL, extracts its readable content and generates an AI summary.

Features:
- Website URL input
- Webpage content extraction using Cheerio
- AI-based summarization using OpenAI

Folder: `website-summarizer/`

## Technologies Used
- JavaScript
- React.js
- Node.js
- Express.js
- SQLite
- HTML and CSS
- OpenAI API

## Requirements
- Node.js
- npm
- OpenAI API key for Programs 2 and 3

Refer to the README file inside each project folder for setup instructions.

Never commit actual API keys or secret credentials to this repository.
